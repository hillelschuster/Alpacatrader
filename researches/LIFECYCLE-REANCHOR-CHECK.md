# REANCHOR CHECK — read before every stage, every run, every report

The mental mode (owner-directed, 2026-10-02). If a design choice cannot be justified by a
line below, it is drift.

1. **Inefficiency**: at an early causal moment the actual top gainers contain a wildly
   disproportionate share of the day's extreme winners. We are buying an OPTION on the tail.
2. **Basket = competing claims**: ranks 2–5 contain monsters; early identification is
   uncertain BY NATURE. Ownership architecture (slots/weights/rotation) is a discovery
   target to be PROVEN, never a simulator default.
3. **Window, not session**: the phenomenon is a finite window (catalyst → climb → climax →
   relaxation). Unconditional hold is a RULER, never a strategy. A fixed endpoint must
   never define the economics.
4. **Decision object**: where does the NEXT DOLLAR go right now — this name / a sibling /
   an emerging outsider / partial cash / full cash / a resurrection. It can change minute
   by minute; 0..N holdings; a monster may deserve more, a fading rank-1 may deserve zero.
5. **Personality = latent character via many changing observables + transitions.** Not a
   flag, not `no_high_10`, not `dd < X`. The ROUTE is the object.
6. **Objective**: executable EV through the window, TAIL PRESERVED, DUD TAX MEASURED.
   Never classification accuracy, never "winners identified", never a benchmark delta.
7. **Labels are rulers.** Route/outcome labels group anatomy; they are never the deployed
   target. High separability of a forward-defined label is not alpha.
8. **Discovery before freeze.** Use the first 533 days aggressively; the second half is
   spent once, on a mature thesis. No freeze, no validation, no "policy result" before then.
9. **Anti-drift checklist** (trained-default traps to refuse): predict-the-monster framing;
   hold-vs-sell as the core question; fixed clocks/endpoints as truth; mechanical max-3;
   optimizing AUC/accuracy; benchmark-delta worship; complexity for its own sake; any
   architecture preserved because it exists.
10. **Do not infer “past the pop” from negative returns to a fixed endpoint.** First
    separate executable forward opportunities, subsequent giveback, and dud tax on
    the same causal roster. Early-ramp selection is a parallel hypothesis, not a
    silent substitution. Profitability must come from actual sale prices, not highs.
